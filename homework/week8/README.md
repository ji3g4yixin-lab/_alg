* 爬山演算法：將所有城市隨機洗牌，生成隨機初始路徑，計算其總距離。隨機選擇兩個城市位置，計算新鄰居路徑的總長度，若新長度小於當前長度，則無條件接受該解，更新當前狀態並將新長度記錄；若新長度未改善，保持原狀態。直至達到設定的最高迭代次數後停止。
* 模擬退火法：隨機產生路徑後，設定迴圈計算的最大值與最低值。透過隨機抽選兩點，計算前後差值，若差值小於零則接受新路徑。直至迴圈計算至最低值後終止。
