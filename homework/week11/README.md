----------------------------------------------------
1. 用數值方法來算單變數微分和積分
2. 用蒙地卡羅法來算單變數積分
3. 用數值方法來算 n 變數微分(梯度）和積分（超體積）
4. 用蒙地卡羅法來算 n 變數積分(超體積）
5. 請用黎曼積分法，寫函數 integral(f, low, high) 來做 n 變數積分（n 是 low, high 的陣列長度）
6. 改用蒙地卡羅法做 n 變數積分，題目同上一題
----------------------------------------------------
