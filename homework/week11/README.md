# 數值微積分與高維度積分實驗 (Numerical Calculus & High-Dimensional Integration)

本專案使用 Python 與 NumPy 實作基礎數值微積分演算法，涵蓋**單變數與多變數的數值微分（梯度）**，以及**黎曼積分法（Riemann Sum）**與**蒙地卡羅積分法（Monte Carlo Integration）**。

程式特別針對 $1, 2, 5, 100$ 維空間進行超體積積分測試，藉此驗證傳統網格法在高維空間遭遇的**維度災難（Curse of Dimensionality）**，並展示蒙地卡羅法在處理高維問題時的優勢。

---

## 📋 功能總覽

| 函式名稱 | 數學方法 | 適用維度 | 核心原理說明 |
| :--- | :--- | :--- | :--- |
| `diff_1d` | 中央差分法 (Central Difference) | 1D | 利用 $f(x+h)$ 與 $f(x-h)$ 估算切線斜率，誤差階數為 $O(h^2)$。 |
| `integral_1d_riemann` | 中點黎曼和 (Midpoint Rule) | 1D | 取每個子區間的中點函數值進行加總，精確度高於左/右端點法。 |
| `integral_1d_mc` | 蒙地卡羅法 (Monte Carlo) | 1D | 在區間內均勻隨機撒點，以樣本平均值乘以區間長度估算積分。 |
| `gradient_nd` | 多變數中央差分法 | $n$D | 針對各座標軸分別進行微小擾動 $\pm h$，計算偏導數並組成梯度向量 $\nabla f$。 |
| `integral_riemann` | 多維中點黎曼和 | $n$D | 使用 `itertools.product` 遍歷 $n$ 維網格中點，加總超立方體微元體積。 |
| `integral_mc` | 多維蒙地卡羅法 | $n$D | 支援 NumPy 批次向量化運算，在 $n$ 維超矩形內隨機取樣估算超體積積分。 |

## 💡 關鍵技術亮點與實驗觀察

1. **維度災難保護機制 (`integral_riemann`)**
   * 若每個維度切分 $k$ 等分，在 $d$ 維空間中總網格數為 $k^d$（呈指數成長）。當 $d = 100$ 時，即使每維只切 $2$ 份也會產生 $2^{100}$ 個網格點導致記憶體溢位或當機。
   * 程式碼內建自動降級邏輯，當未指定 `bins_per_dim` 時會根據維度動態調整網格密度，並在超高維度時發出警告。

2. **蒙地卡羅法的收斂優勢 (`integral_mc`)**
   * 蒙地卡羅法的估算誤差為 $O(1/\sqrt{N})$（$N$ 為取樣數），**與空間維度 $d$ 無關**。因此在 $100$ 維空間中，僅需 $200,000$ 個隨機樣本與不到 $0.2$ 秒的時間，即可逼近理論解 $33.333333$。

3. **向量化加速支援**
   * `integral_mc` 優先嘗試將 `(samples, dim)` 的二維座標矩陣一次性傳入目標函數 `f(points)` 進行 NumPy 向量化運算；若目標函數僅支援單點一維陣列輸入，則會自動退回逐列計算，兼顧執行效率與通用性。
