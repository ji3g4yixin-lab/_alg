* 老鼠走迷宮問題 (DFS)
先取得迷宮邊界大小，行走至鄰近位置後要先判斷有無超過迷宮邊界，有沒有碰到障礙物或牆壁，如果沒有則將已經造訪過的位置加入visited集合中，標記已經去過的位置，並將路過的路徑加入path。直到達到終點（輸出路徑）或無路可走。
* 狼羊甘藍菜過河問題 (BFS)先標記兩岸分別為編號０和１，分別標示'農夫', '狼', '羊', '菜'四個物件的初始狀態為０（都在左邊的岸上），並設定終止狀態為所有物件的狀態皆標記為１（即都在右邊的岸上），每次移動後檢查四個物件有沒有不合規定的狀態（狼羊同岸且無農夫或羊菜同岸且無農夫），若符合則將狀態加入queue，直到達成全員過岸（輸出每次的移動步驟queue）或宣告失敗。
